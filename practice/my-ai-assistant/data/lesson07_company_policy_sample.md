# 사내 업무자료 관리 및 AI 활용 운영규정 (교육용 모의 문서)

> **문서번호:** EDU-POL-2026-01 · **버전:** 1.0 · **시행 예시일:** 2026-11-01  
> **문서 성격:** AI Agent Engineering 실습을 위해 작성한 **가상의 회사 내부 규정**입니다. 실제 법령, 회사 정책, 법률 자문이 아니며 실존 조직에 적용되지 않습니다. 모든 직원, 부서, 기한, 금액은 실습용 가상 정보입니다.

## 제1조 목적과 적용 범위
이 규정은 가상회사 새봄테크의 업무자료 작성, 접근, 보관, 폐기, AI 도구 활용 절차를 일관되게 설명하기 위한 교육용 예시이다. 정규직, 계약직, 외부 협력업체 담당자가 회사 시스템을 통해 취급하는 전자문서에 적용한다. 공개 홍보자료와 개인적으로 작성한 비업무 기록은 별도 정책에 따르며, 이 문서만으로 다른 조직의 자료를 처리할 권한이 생기지 않는다.

## 제2조 자료 등급 분류
업무자료는 공개, 내부, 기밀 세 단계로 구분한다. 공개 자료는 대외 배포 승인을 받은 보도자료나 공개 가이드이다. 내부 자료는 사내 구성원에게만 제공하는 회의록, 업무 매뉴얼, 프로젝트 일정표 등이다. 기밀 자료는 고객 연락처, 계약 단가, 인사평가, 접근 토큰, 비밀번호 등 외부 공개 시 피해가 생길 수 있는 정보를 포함한다. 자료 등급이 혼재하면 가장 높은 등급을 적용한다. 작성자는 문서 제목 또는 메타데이터에 등급과 관리 부서를 기록한다.

## 제3조 접근 권한 신청
내부 또는 기밀 자료의 열람 권한은 업무상 필요한 범위에서만 부여한다. 직원은 사내 권한 신청 시스템에서 자료명, 사용 목적, 필요한 기간을 제출해야 한다. 내부 자료는 해당 부서 책임자가 검토하고, 기밀 자료는 부서 책임자와 정보보호 담당자의 승인을 모두 받아야 한다. 권한 신청이 반려되면 신청자는 사유를 확인하고 보완하여 다시 제출할 수 있다. 프로젝트가 종료되거나 담당 업무가 변경되면 불필요한 권한을 회수한다.

## 제4조 외부 AI 서비스 이용
공개 자료는 사내 승인된 AI 서비스에 입력할 수 있다. 내부 자료는 서비스의 데이터 보관·학습 이용 조건을 확인한 후 별도의 사전 승인을 받은 경우에만 전송한다. 기밀 자료, 주민등록번호, 비밀번호, API 키, 고객의 민감한 정보는 외부 AI 서비스에 입력하지 않는다. 시험용 RAG 실습에는 익명화된 샘플이나 본 교육용 모의 규정처럼 공개해도 문제가 없는 문서만 사용한다. 승인되지 않은 무료 API라도 외부 서비스라는 사실은 바뀌지 않는다.

## 제5조 파일 보관 및 버전 관리
업무자료는 승인된 문서 저장소에 보관한다. 담당자는 수정일, 작성자, 버전, 변경 요약을 관리하고 이전 버전이 필요한 경우 복원 가능 여부를 확인한다. 임시 복사본은 개인 메신저나 개인 클라우드에 장기간 보관하지 않는다. 동일한 문서가 여러 위치에 복제되었을 때에는 공식 저장소의 최신 승인 버전을 기준으로 한다. AI 검색용 벡터 데이터도 원문 출처와 문서 버전을 추적할 수 있어야 한다.

## 제6조 자료 보존과 삭제
프로젝트 일반 업무자료의 기본 보존기간은 프로젝트 종료 후 3년으로 정한다. 다만 계약서, 회계 증빙, 법적 보존 의무가 적용되는 자료는 이 규정보다 관련 법령과 별도 보존 정책을 우선한다. 보존기간이 지난 자료는 관리 부서의 검토 후 승인된 절차로 삭제한다. 원문이 삭제되거나 접근 권한이 취소되면 검색 인덱스와 임베딩 벡터에서도 대응하는 기록을 제거하도록 요청한다. 백업 데이터는 별도 복구 정책에 따른다.

## 제7조 보안사고 및 오발송 보고
기밀 자료가 외부에 잘못 전송되었거나 API 키가 공개된 사실을 발견하면 담당자는 지체 없이 정보보호 담당자에게 보고한다. 사고 보고에는 발생 시각, 노출 가능 자료, 사용한 서비스, 임시 차단 조치 등을 포함한다. API 키가 노출된 경우 키를 폐기하고 재발급하며 관련 접근 로그를 점검한다. 증거 보존을 위해 개인이 임의로 기록을 삭제하지 않는다.

## 제8조 RAG 검색 결과의 검증
AI 검색 시스템은 검색된 문서 제목, 출처, 버전, 접근 권한을 확인할 수 있도록 설계한다. 코사인 거리가 작다는 이유만으로 검색 결과를 확정적 사실이나 최종 승인 답변으로 간주하지 않는다. 질문과 관련한 문서가 없거나 서로 충돌할 때에는 답변을 보류하거나 담당자 확인을 요청한다. 내부 문서 검색에서는 사용자가 열람할 수 있는 문서만 후보에 포함되어야 한다. 모델 교체 시 원문과 질문을 같은 임베딩 모델로 벡터화하여 평가한다.

## 제9조 교육 및 운영 점검
신규 구성원은 자료 등급과 외부 AI 활용 규칙을 안내받고, 연 1회 보안 교육을 이수한다. 각 부서 담당자는 분기별로 접근 권한과 만료된 자료를 점검한다. 교육용 검색 실험에서는 동일한 원문과 질문을 유지한 채 청크 크기, 문단 분할, 오버랩 설정을 변경하고 Top-K 결과를 비교한다. 기록에는 검색된 근거가 실제 질문에 답하는지와 누락된 조건이 있는지도 함께 남긴다.

## 부칙
이 문서는 학습자가 법령형 제목과 조문 구조, 여러 업무 주제가 섞인 긴 자료를 대상으로 청킹과 검색을 연습하도록 작성되었다. 숫자와 절차는 실습용 설정이므로 실제 회사의 법적 의무나 보안 기준으로 사용해서는 안 된다.
