# Lesson 07 — 문서 분할 실습용 강의 안내

## 과제 제출
이번 주 과제 제출 기한은 금요일 오후 6시입니다. 제출 시간이 지나면 학습관리시스템에서 과제 업로드 메뉴를 이용할 수 없을 수 있습니다.
제출할 파일은 과제 안내에 적힌 형식을 확인한 다음 학습관리시스템의 과제 제출 메뉴에 업로드하세요.

## 수업 환경
이번 실습에는 Python 3.12와 VS Code를 사용합니다. 로컬 프로젝트의 가상환경에서 필요한 패키지를 설치해야 합니다.
API Key는 로컬 .env 파일에만 저장하며 GitHub나 메신저에 공개하면 안 됩니다.

## 질문 및 문의
과제 관련 문의는 수업 질문 게시판에 남깁니다. 질문 게시판에 오류 메시지를 올릴 때는 비밀번호나 API Key를 가리고 공유하세요.
실습 중 실행 결과가 예상과 다르면 실제 명령과 출력 내용을 확인한 후 문의합니다.

## 평가와 근거
실습 결과는 실행 화면과 테스트 출력 등 직접 확인할 수 있는 증거를 기준으로 기록합니다. 검색된 문단의 유사도 점수가 높다고 답변의 정확성이 보장되지는 않습니다.
청크 크기와 중첩을 바꾸면 문맥 보존과 검색 결과가 달라질 수 있으므로 같은 질문과 같은 평가 기준으로 비교합니다.
